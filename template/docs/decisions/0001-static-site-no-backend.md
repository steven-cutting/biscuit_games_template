# Decision 0001: A static site with no backend

Carried from Poodl's decision 0001. The game is a single-page static site prerendered by
`adapter-static`, with no server, no accounts and no database. The record will set out
the context, the choice, what it costs, such as having nowhere to keep anything beyond
the visitor's own browser, and what would have to change before a backend was worth
reconsidering.
