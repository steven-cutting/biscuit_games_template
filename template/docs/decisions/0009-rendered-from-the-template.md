# Decision 0009: Rendered from the template

This game is rendered by Copier from the Biscuit Games template rather than copied from
another game. The record will explain why Copier was chosen, how files divide into
managed files the template merges on every update and seed files that belong to the game
alone, why the seed inventory is frozen once released, and what `copier update` does to
each.
