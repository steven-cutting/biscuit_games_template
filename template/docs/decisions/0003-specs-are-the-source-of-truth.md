# Decision 0003: Specifications decide behaviour

Carried from Poodl's decision 0003. Behaviour is specified in Allium under `docs/specs/`
before it is built, and when the specification and the code disagree the specification
wins. The record will explain why a written specification is worth its upkeep, how the
pinned checker keeps it honest, and what would make the practice worth abandoning.
