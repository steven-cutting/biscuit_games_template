# Decision 0005: A component workshop

Carried from Poodl's decision 0006. Storybook is the component workshop: every component
is built and reviewed there in each state its surface names, with accessibility checks
over every story, and the story run is part of `just check`. The record will explain
what the workshop catches that unit tests do not, and what it costs to keep.
