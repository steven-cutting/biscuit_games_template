# Decision 0006: Visual review in Chromatic

Carried from Poodl's decision 0008. Chromatic publishes the workshop for visual review,
from its own workflow and from `just chromatic`. The record will cover its entry points,
why a pull request from a fork is refused, where the project token lives, which branch
accepts changes automatically, and why the workflow skips cleanly when no token is
configured.
