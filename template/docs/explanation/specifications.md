# Specifications

Why behaviour is written down before it is built, and how the written form relates to
the code. The page explains the Allium modules under `docs/specs/`, starting from the
single root module this game is rendered with, the difference between what a module
states and what the platform states, how figures in a `config` block are mirrored in
code, and how drift is caught.
