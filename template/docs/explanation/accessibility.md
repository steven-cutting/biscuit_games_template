# Accessibility

The accessibility obligations a game owes, and where each one is stated. The page
summarises what the platform's specifications require of every surface: a non-colour
indication for every state, accessible names, keyboard operation, comfortable touch
targets, announcements through the platform's announcer and legible contrast. It
explains which obligations the platform components already meet and which this game
meets itself.
