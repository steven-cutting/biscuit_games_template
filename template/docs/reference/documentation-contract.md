# Documentation contract

The rules every handbook page obeys. The page defines the manifest, the frontmatter each
page repeats from it, the single owner of every topic, the minimum length, the markers a
finished page may not carry and reachability from the documentation map. It adds one
section on managed and seed pages: what `copier update` does to each, and why the seed
inventory is frozen once a release is tagged.
