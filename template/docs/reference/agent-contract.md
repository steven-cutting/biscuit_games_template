# Agent contract

What the agent guidance in this repository must be, and how the gate checks it. The page
describes `AGENTS.md` as the single source of truth, the phrases it has to carry, the
canonical skills under `.agents/skills/`, the exact one-sentence body every provider
bridge must keep, and the two byte-pinned adapters. `just check-agents` runs the
validator that enforces all of it.
