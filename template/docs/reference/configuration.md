# Configuration

Every setting this game reads, and where it is set. The page lists the environment
variables the build honours, including `BASE_PATH` for a project Pages site, the pinned
tool versions and the files that carry them, and the six platform figures
`src/lib/config.ts` mirrors from the specifications. A figure this game adds is listed
below the platform's own, beside the module that states it.
