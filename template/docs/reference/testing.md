# Testing

What each test suite covers and how it runs. The page tables the managed suites the
template ships, such as the port tests and the platform specification comparison,
together with the seed suites for the lockup and the route, and records the tools, the
environments, the coverage floor over `src/lib/` and the recipe that runs each suite
inside `just check`.
