# Troubleshooting

Symptoms, causes and fixes for the failures people actually meet. The page covers a 401
from GitHub Packages during an install, a hook environment that fails to build, a
missing browser for the story run, a specification gate with no checker installed, a
deployment that serves a blank page under the wrong base path, and a gate that stops
because a generated file appeared in the worktree.
