# Maintenance

The routine work that keeps this game healthy between changes. The page sets out a
schedule for dependency, platform and template updates, reviewing the pinned hook and
action versions, renewing the GitHub Packages token before it expires, and checking that
the deployed site still matches `main`. Its secrets section says where each credential
lives and why none belongs in the repository.
