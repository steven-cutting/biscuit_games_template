# Repository map

Where everything in this repository lives, and why it lives there. The page walks the
top level, then `src/lib/` with its components and ports, `tests/`, `stories/`, `docs/`
with the handbook and the specifications, and the eight checkers under `scripts/`. It
separates the files the template manages from the files that belong to this game alone,
so a reader knows which edits an update will merge.
