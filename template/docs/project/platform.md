# The platform upstream

What `@steven-cutting/biscuit-games` decides for this game, which version of it is
installed, and where to read the rest. The page names the components, the token
stylesheet and the three specification modules the package ships, explains how this
game's restatements are held equal to them, and states the installed version as the one
`package.json` pins rather than as a number that would drift.
