# Test and debug

How to run the suites and read their failures. The page shows the narrow recipes for
unit tests, coverage, the story run and the static checks, how to run a single test file
or a single case, how to reproduce a failure the continuous integration run reported,
and how to build and preview the site locally under the same base path the deployment
uses.
