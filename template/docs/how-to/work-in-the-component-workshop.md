# Work in the component workshop

How to build and review a component in Storybook before a route hosts it. The page
covers serving the workshop, writing a story for every state a surface names, injecting
port fakes the way a test does, the accessibility checks that run over each story, and
the platform's own workshop shown beside this one. Its worked example is the seed lockup
story this game starts with.
