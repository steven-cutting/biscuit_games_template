# Maintain dependencies

How to move a pinned dependency without breaking the gate. The page covers bumping npm
and Python packages to exact versions, regenerating both lockfiles, updating a pinned
hook or GitHub Action by its commit, moving the platform package to a new release, and
taking a template update instead when the change belongs in every game rather than in
this one.
