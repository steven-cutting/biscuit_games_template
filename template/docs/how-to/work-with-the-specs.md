# Work with the specifications

How to change behaviour starting from the Allium specifications. The page describes the
root module this game starts with, how to add a module beside it, how `just check-specs`
and `just analyse-specs` run the pinned checker, how a waiver is recorded against the
version it was verified on, and how a clause restated from the platform stays word for
word equal to the shipped text.
