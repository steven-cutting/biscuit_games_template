# Develop locally

How to get a working checkout and keep it working. The page covers the tools to install,
the GitHub Packages token that belongs in `~/.npmrc` and never in the repository,
`just initialize` and what it runs, serving the game with `just dev`, building it under
a project base path, and what to do when a dependency or a hook environment falls out of
step with the lockfiles.
