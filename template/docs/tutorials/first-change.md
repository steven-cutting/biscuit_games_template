# Make your first change

A guided pass from a fresh clone to a green gate that touches every layer once. The
tutorial initialises the toolchain, then changes the root specification module, the seed
test that holds it and the seed component that renders it, running the narrowest recipe
after each step and `just check` at the end, so a newcomer sees how specifications,
code, tests and documentation move together.
